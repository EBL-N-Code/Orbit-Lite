Apex is a client-side Minecraft mod that integrates an AI chat interface directly into your game. No setup is required, simply install the mod, launch Minecraft, and start chatting with the AI instantly.

To open the Chat UI, click on **Right Shift** or run the command `./chat`.  
More information can be found in https://apexmod.tech

### Usage & Plans
The mod is **100% Free to use** but comes with daily usage limits.
- Free Plan: Every new user receives access to a free daily usage limit.
- Pro & Ultimate Plans: Paid plans with higher daily limits, extended context window and advanced features. Currently under development.
- **If you are interested in purchasing a paid plan when available, submit your Minecraft username in the interest field on the website. The more interest we get, the faster we continue the development and the faster these plans will be released.**

### Token Usage & Context Window
Each message consumes tokens depending on the length of your input, the AI response and the cached conversation tokens.  
The context window determines how much of your previous conversation the AI remembers, affecting response quality and continuity.

### Installation
1. Ensure you have Minecraft with Fabric installed (latest version recommended).
2. Download Apex and place it in your mods folder.
3. Launch Minecraft and open the chat UI via `./chat` or **Right Shift**.
